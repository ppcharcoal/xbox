Wersja dla **Windows 10/11 (64-bit)**: pobierz **Xbox-Windows.zip**, rozpakuj całe archiwum i uruchom **Xbox.exe**.

- obraz z karty przechwytującej HDMI (USB) przez mpv z najmniejszym opóźnieniem, z dźwiękiem karty
- sam znajduje kartę i najlepszy tryb (1080p, najwięcej klatek)
- Ctrl+Shift+M: menu ustawień obrazu, Ctrl+F: pełny ekran
- wygaszacz i uśpienie ekranu nie włączają się, dopóki okno jest otwarte
- `Lista-kart.bat`: wykryte karty, tryby i dźwięk

Instrukcja w `CZYTAJ.txt` w archiwum. Na Archu: `git clone https://github.com/ppcharcoal/xbox && cd xbox && makepkg -si`.
